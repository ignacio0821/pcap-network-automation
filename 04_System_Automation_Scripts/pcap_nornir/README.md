# Multi-Vendor Infrastructure Automation Engine (Nornir & OOP Framework)

## 📌 Architectural Overview
This repository contains a production-grade, object-oriented network automation orchestration engine built on top of the **Nornir v3 framework**. The tool decouples active automation tasks from inventory states using flat, declarative YAML data structures.


The core architecture models an enterprise-grade automated compliance engine, utilizing pure Python **OOP Data Fortification (Name Mangling)** to safeguard runtime state tracking variables against unauthorized injection.

## 🛠️ Core Technology Stack
*   **Orchestration Engine:** Nornir v3 (Multi-threaded framework execution)
*   **Device Driver Abstraction:** Netmiko / NAPALM
*   **Data Structures:** YAML v1.2 (Strict declarative mapping)
*   **Development Metrics:** Python 3.13 Virtual Environment Compliance

## 🚀 Execution & Environment Initialization

### 1. Recreate the Virtual Environment
To deploy this automation framework locally, initialize your virtual environment and install the required dependencies using the project blueprint:
```bash
python -m venv .venv
source .venv/bin/activate  # On Windows use: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Run the Compliance Framework
Execute the core inventory object factory and task runner engine via the terminal terminal line:
```bash
python nornir_inventory_factory.py
```
